# Provenance

The original repository contained the coursework report and three MQTT subscriber implementations: MapReduce-style batch processing, stream windows/alerts, and ThreadPoolExecutor-based parallel analytics.

The 2026 portfolio pass:

- removes the historical private broker IP from active defaults;
- removes the student identifier from the public report header;
- extracts deterministic processing logic into a reusable module;
- adds input validation and automated tests;
- modernizes the MQTT callback API;
- documents algorithmic boundaries and production gaps;
- adds an implementation-derived architecture visual.

These improvements are later portfolio engineering work and are not represented as if they were all part of the original lab submission.
